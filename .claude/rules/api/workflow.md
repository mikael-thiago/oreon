## Development Workflow
- Use backend-architect agent to design high level solutions for the problems
- Use backend-developer agent to implement the solution proposed and make lower level decisions
- Use backend-reviewer agent to understand the solution provided by the backend-architect, review the changes implemented by the backend-developer and ensure that the specifications were met
- DO NOT write documentation files without consent
- Always provide to the user clear details of what is going to be implemented by the agents
